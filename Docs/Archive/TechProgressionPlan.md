# MO Framework Technology Progression Plan
## Stone Age to Dark Ages (~1000 hours single-player)

---

# Overview

This document outlines the complete technological progression from earliest human tool use through the medieval period. The progression is divided into 8 distinct eras, each with its own skill requirements, craftable items, and unlockable recipes.

**Design Principles:**
- Each era unlocks naturally from the previous
- No dead ends - every skill path leads somewhere useful
- Parallel progression paths prevent frustration
- Critical items have multiple acquisition methods
- Time gates through skill XP, not artificial timers

**Era Time Estimates (varies by playstyle):**
| Era | Hours | Cumulative | Focus |
|-----|-------|------------|-------|
| Early Paleolithic | 0-50 | 50 | Basic survival, simple tools |
| Middle Paleolithic | 50-150 | 150 | Fire mastery, refined tools |
| Late Paleolithic | 150-300 | 300 | Hunting weapons, fishing |
| Mesolithic | 300-400 | 400 | Microliths, composite tools |
| Early Neolithic | 400-550 | 550 | Agriculture, pottery |
| Late Neolithic | 550-700 | 700 | Weaving, permanent structures |
| Chalcolithic | 700-850 | 850 | Native copper, early metallurgy |
| Bronze Age | 850-950 | 950 | Bronze alloys, advanced crafts |
| Iron Age | 950-1000+ | 1000+ | Iron smelting, steel |

### Key Challenge: Iron Smelting
Iron requires much higher temperatures than copper/bronze:
- Copper melts at 1085°C
- Bronze melts at ~950°C
- Iron melts at 1538°C
- Bloomery iron produced at 1200-1300°C (below melting point)

Iron doesn't melt in a bloomery - it becomes a spongy "bloom" mixed with slag that must be hammered to consolidate.

# APPENDIX B: PARALLEL PROGRESSION PATHS

Players can focus on different paths:

**Hunter Path:** Hunting → Ranged → Leatherworking → Trading
**Gatherer Path:** Foraging → Herbalism → Medicine → Cooking
**Crafter Path:** Stoneworking → Woodworking → Smithing
**Farmer Path:** Foraging → Farming → Pottery → Trading
**Warrior Path:** Melee → Defense → Smithing → Leadership

All paths eventually require some cross-training but allow different playstyles.
