# MO Framework UI Test Output

This directory contains UI test results generated by the automated testing system.

## Files

- `ui_test_results.txt` - Latest test run results

## Running Tests

### From Editor Menu
1. Start Play In Editor (PIE)
2. Go to **MO Framework** menu in the menu bar
3. Under **UI Testing** section:
   - **Run All UI Tests** - Run complete test suite
   - **Run Inventory Tests** - Test inventory menu only
   - **Run Crafting Tests** - Test crafting menu only
   - **Run Building Tests** - Test building menu only
   - **Run Input State Tests** - Test cursor/input blocking

### From Console (in PIE)
```
MO.UI.RunAllTests          - Run all tests
MO.UI.RunTests Inventory.* - Run tests matching pattern
MO.UI.RunTest Inventory.Open - Run single test
MO.UI.ListTests            - List available tests
MO.UI.State                - Print current UI state
```

### From Python
```python
import view_ui_test_results
view_ui_test_results.print_summary()
view_ui_test_results.print_all_tests()
view_ui_test_results.print_slowest_tests(10)
```

## Adding New Tests

1. Add test function to `MOUITestSubsystem.cpp`:
```cpp
FMOUITestResult UMOUITestSubsystem::Test_MyNew_TestCase()
{
    LogTest(TEXT("Testing: My new test case"));

    // Test logic here
    if (!SomeCondition())
    {
        return MakeResult(TEXT("MyNew.TestCase"), false, TEXT("Condition not met"));
    }

    return MakeResult(TEXT("MyNew.TestCase"), true);
}
```

2. Register in `RegisterTests()`:
```cpp
TestRegistry.Add(TEXT("MyNew.TestCase"), [this]() { return Test_MyNew_TestCase(); });
```

3. Recompile and run tests
